背景

Claude Code をはじめ、CLIで動くコーディングエージェントが増え、
ターミナルで過ごす時間が長くなってきた。

コーディングのような重い作業ではなく、ちょっとした質問を声でさっと聞ける。
ターミナルから出ずに声でLLMと会話できたら便利だなと思って作りました。

また、すべてローカルで完結させることで、
プライバシーやLLMの利用料金を気にせず使えるようにしたかった。

What is voivoi?

voivoi は、ターミナルで完結するローカル音声LLMアプリです。

マイクに話しかけるだけで、音声認識 → LLM応答 → 読み上げまで一連の処理を行います。
クラウドAPI不要。すべてローカルで動作します。

STT - 音声認識

  • Whisperによるローカル文字起こし
  • 無音検知で自動録音停止
  • 日本語・英語対応
  • モデルサイズ選択可能

LLM - 応答生成

  • OllamaでローカルLLM実行
  • 任意のモデルを指定可能
  • 会話履歴を保持
  • ツール呼び出し対応

TTS - 音声合成

  • pyttsx3でオフライン音声合成
  • バージイン（割り込み）対応
  • 読み上げ中に話すと中断
  • 読み上げON/OFF切り替え可能

Roadmap
Tool

ツール拡充

Web検索は実装済み。ファイル操作やコード実行、カレンダー連携などのツールも追加予定。LLMが自律的にツールを選択・実行するエージェントを目指す。

MCP

MCP連携

Model Context Protocol サーバーへの接続をサポートし、外部ツール・データソースとの連携を可能にする。

Memory

長期記憶

現在はセッションごとに記憶がリセットされる。会話を跨いだ長期記憶を導入し、過去の内容を踏まえた応答を可能にする。
